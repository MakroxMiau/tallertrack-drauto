# TallerTrack / Dr.Auto 

Sistema web de seguimiento de reparaciones vehiculares para talleres mecánicos.

## Problemática
Los talleres mecánicos pequeños no tienen visibilidad en tiempo real para sus clientes sobre el estado de las reparaciones, generando desconfianza y sobrecarga de consultas.

## Solución
Aplicación web que permite al cliente tracking en tiempo real, notificaciones automáticas y al taller gestión digital de órdenes de trabajo.

## Stack Tecnológico
- Frontend: React.js + Tailwind CSS
- Backend: Node.js + Express
- BD: MySQL
- Deploy: Render + Railway
